# Changelog

## 0.1.1 - 2026-08-26

- Established `0.1.1` as the new public version baseline.
- Added Windows x86/x64 installers and macOS/Linux portable packages.
- Added the Windows in-page token status bar with external-overlay fallback.
- Moved Windows in-page CDP to required loopback port `127.0.0.1:19222` and migrated older shared-port settings.
- Added input, output, cache, context, and wall-clock token-rate metrics.
- Added release automation, fixed-sample parser tests, privacy documentation, and package checksums.
